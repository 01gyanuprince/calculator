# Calculator 
A simple python program to parse comma seperated numbers and run calculations.

## Installation and Setup
1. open your terminal and navigate to your directory: 
   ```bash
   cd calculator
   ```
2. Run the program.
    ```                                                  python
    # for addition
    python run add.py
    print('it really colors code by mentioning language')
    # for subtraction, first argument accepts postive value and all successor values are accepted as negative.
    python run sub.py
    ```
## Features
- Intake numbers seperated by commas
- Calculates sum
